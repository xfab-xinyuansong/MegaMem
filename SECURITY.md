# Security Policy

Do not report credentials, private enterprise documents, model outputs containing
sensitive data, or exploitable vulnerabilities in public issues.

Before opening a report, remove API keys, endpoint tokens, tenant identifiers, document
contents, and generated index paths. Use the repository owner's private GitHub contact
channel for security-sensitive reports.

The public artifact reads local corpora and can call configured model providers. Operators
are responsible for data-processing agreements, provider retention settings, access
control, and secret management in their deployment environment.
